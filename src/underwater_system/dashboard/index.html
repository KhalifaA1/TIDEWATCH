ⓘ Simulation model / limitations

This monitor displays simulation telemetry. Propulsion and classifier details appear when nodes connect. Acoustic noise, echoes, localization drift, and network outages are modeled; physical hardware behavior still requires field validation.

Sonar returns and hydrophone signatures are synthesized for the virtual scene. A numeric feature classifier is a simulation baseline; trained-model status is reported separately. Classification confidence and accuracy on this scene do not establish real-world detection performance.

Diver protection assigns escort positions around the moving diver; autonomous survey assigns exploration targets without using the diver. The protection radius is a proximity assessment volume, not a physical barrier. Coverage comes from measured observations and depends on node availability. Dashed lines show assigned goals; they do not promise a collision-free route.

Coverage is based on observations. Object positions include physical uncertainty; classification confidence is a separate estimate. Surface/obstacle points are reported sensor observations. The scene’s reference grid is visual guidance, not an observed map. Evaluation metrics compare estimates with simulator truth, which is excluded from normal detections and navigation decisions.

Telemetry source: ROS 2 simulation adapter · local monitoring gateway.
